# Agent Instructions

Complete context for AI to process resume tailoring.

## Your Task
Transform a user's base resume to perfectly match a job description using proven ATS-beating strategies.

## Input You'll Receive
1. **Base Resume** - User's original resume content
2. **Job Description** - Target job posting text

## Output You Must Provide
A tailored resume that maximizes ATS compatibility and keyword matching.

## Core Strategy: Verbatim Keyword Matching

**CRITICAL:** Copy EXACT phrases from the job description. Do not paraphrase or use synonyms.

**Example Process:**
- Job says: "Experience with data visualization tools like Tableau or Power BI"
- You write: "Experience with data visualization tools like Tableau or Power BI"

## Step-by-Step Process

### 1. Extract Keywords
- Scan job description for technical skills
- Identify role-specific terminology  
- Note company values if mentioned
- Find section headers/categories

### 2. Match Role Title
- Change user's job title to match target role
- Only if responsibilities genuinely align

### 3. Restructure Experience
- Use job description's section headers
- Mirror their categorization
- Place matching content under each section

### 4. Inject Keywords
- Add exact phrases throughout experience bullets
- Maintain natural flow and accuracy
- Don't fabricate experiences

### 5. Format for ATS
- Single column layout
- Standard fonts (Calibri/Arial)
- .docx output
- No tables or graphics
- Standard bullet points

## Values Alignment
If job mentions company values, create a section like:

**Values Alignment**
• Bold: Act with determination in driving data solutions
• Credible: Maintain rigorous standards in analysis
• Human: Focus on positive stakeholder impact

## Remember
- Every resume is unique per job
- Accuracy is essential - don't fabricate
- ATS systems look for exact matches
- Generic resumes fail 60-80% of screenings
