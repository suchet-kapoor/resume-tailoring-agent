# User Guide

## Quick Start

### Step 1: Upload Your Resume
- Save your current resume as PDF or DOCX
- This is a one-time setup

### Step 2: Get Job Description  
- Copy the job posting text
- Paste it when prompted

### Step 3: Get Tailored Resume
- Receive ATS-optimized .docx file
- Download and use for application

## That's it!

The agent handles all the ATS optimization and keyword matching automatically.
