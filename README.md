# Resume Tailoring Agent 🎯

> Transform your resume to match any job description using battle-tested ATS-beating strategies

## Overview

This agent implements the proven methodology from **"How I Got 6 Interviews in One Week"** by Uchenna Ejike. These aren't theoretical tips - they're battle-tested techniques that work against modern Applicant Tracking Systems (ATS) like Greenhouse, Workable, Lever, and others.

## Core Philosophy

**Your CV is not about you. It's about proving you match what they're looking for.**

Everything in this agent stems from this principle.

## How It Works

1. **Upload your resume once** - The agent parses and saves your base information
2. **Paste job description** - Copy any job posting text
3. **Get tailored resume** - Receive an ATS-optimized resume that matches the job

## Key Features

✅ **Verbatim Keyword Matching** - Copies exact phrases from job descriptions  
✅ **Role Title Alignment** - Matches your title to the target position  
✅ **ATS-Friendly Formatting** - Single column, standard fonts, .docx output  
✅ **Experience Restructuring** - Mirrors job description structure  
✅ **Values Alignment** - Integrates company values when mentioned  
✅ **Quantification Enhancement** - Suggests areas for metrics and numbers  
✅ **Cover Letter Generation** - Creates tailored cover letters using proven formula  

## The Proven Strategy

This agent implements Uchenna's methodology that secured **6 interviews in one week**:

### 1. One Resume Per Application
Never send the same resume twice. Every application gets a freshly tailored resume.

### 2. Verbatim Keyword Strategy
Copy exact phrases from job descriptions - not paraphrased, not synonyms, the exact words.

### 3. Mirror Job Description Structure
Structure experience sections to match the job posting's categories and requirements.
